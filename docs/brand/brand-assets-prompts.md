# mediabubble.eg — Brand Asset Generation Prompts

## Brand DNA
- **Navy:** `#072A6B`
- **Electric Blue:** `#2196F3`
- **Yellow / Gold:** `#FFC107`
- **Style:** Flat 2D vector illustration — no 3D renders, no gradients, no shadows
- **Background:** Pure white `#FFFFFF` — all illustrations isolated for easy bg removal
- **People:** Egyptian/Mediterranean appearance, age 25–35, yellow or blue t-shirt

> **Illustration style guide:** Think Dribbble-quality flat UI illustration. Clean geometric shapes, bold flat fills in brand palette, subtle 2-tone navy + blue + yellow accent. No depth effects, no skeuomorphism, no photorealism. Isolated on white for `remove_background` pipeline.

## Generation Pipeline (Codex / gpt-image-1)

```python
import openai, base64, pathlib
from PIL import Image
import io

client = openai.OpenAI()

ASSETS = [
    # (prompt, size, output_path)
    # --- Service Illustrations ---
    ("Flat 2D vector illustration of SEO...", "1792x1344", "public/assets/illustrations/seo-illustration.png"),
    ("Flat 2D vector illustration of paid ads...", "1792x1344", "public/assets/illustrations/paid-ads-illustration.png"),
    ("Flat 2D vector illustration of social media...", "1792x1344", "public/assets/illustrations/social-media-illustration.png"),
    ("Flat 2D vector illustration of brand identity...", "1792x1344", "public/assets/illustrations/branding-illustration.png"),
    ("Flat 2D vector illustration of web development...", "1792x1344", "public/assets/illustrations/web-dev-illustration.png"),
    # --- People ---
    ("Studio portrait photo of Egyptian developer...", "1792x1344", "public/assets/people/developer-macbook.png"),
    ("Studio portrait photo of Egyptian business owner...", "1792x1344", "public/assets/people/business-owner-campaign.png"),
    ("Editorial photo of Egyptian marketing team...", "1792x1008", "public/assets/people/team-strategy.png"),
    # --- Topic Illustrations ---
    ("Flat 2D vector illustration of AI automation...", "1792x1344", "public/assets/illustrations/ai-marketing-illustration.png"),
    ("Flat 2D vector illustration of analytics...", "1792x1344", "public/assets/illustrations/analytics-illustration.png"),
    ("Flat 2D vector illustration of targeting...", "1792x1344", "public/assets/illustrations/targeting-illustration.png"),
    ("Flat 2D vector illustration of teamwork...", "1792x1344", "public/assets/illustrations/teamwork-illustration.png"),
    ("Flat 2D vector illustration of SERP ranking...", "1792x1344", "public/assets/illustrations/serp-illustration.png"),
    # --- Patterns ---
    ("Seamlessly tileable dot-grid pattern...", "1024x1024", "public/assets/patterns/dot-grid-navy.png"),
    ("Abstract wave bubble texture...", "1792x1008", "public/assets/patterns/wave-bubble-texture.png"),
    ("Seamlessly tileable geometric grid overlay...", "1792x1008", "public/assets/patterns/geometric-overlay.png"),
]

for prompt, size, out_path in ASSETS:
    print(f"Generating: {out_path}")
    response = client.images.generate(
        model="gpt-image-1",
        prompt=prompt,
        size=size,
        quality="high",
        n=1,
        response_format="b64_json",
    )
    )
    img_bytes = base64.b64decode(response.data[0].b64_json)
    pathlib.Path(out_path).parent.mkdir(parents=True, exist_ok=True)
    pathlib.Path(out_path).write_bytes(img_bytes)
    print(f"  ✓ Saved {out_path}")

print("All assets generated.")
```

> After generating, convert PNGs to WebP:
> ```bash
> find public/assets/illustrations public/assets/people public/assets/patterns \
>   -name "*.png" -exec sh -c 'cwebp -q 88 "$1" -o "${1%.png}.webp" && rm "$1"' _ {} \;
> ```

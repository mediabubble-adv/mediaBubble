# MediaBubble Egypt - Image Generation Prompts for OpenAI

## How To Use
1. Open ChatGPT or use the OpenAI Images API.
2. Paste the system context once at the start of the image-generation session.
3. Paste one asset prompt at a time.
4. Use **1792x1024** for heroes, insight covers, and about images.
5. Use **1024x1024** for square gallery/card images.
6. Use **high quality** and a **natural / photorealistic** style.

---

## System Context

Paste this once at the start of a new image-generation conversation.

```text
You are a professional photography art director generating imagery for MediaBubble Egypt, a marketing agency based in Hurghada, Egypt.

Creative direction:
- Brand DNA: confident, crafted, calm, strategic, premium but grounded.
- Visual mood: Obsidian Creative Studio meets authentic Red Sea business life.
- Palette cues: deep charcoal / obsidian (#0D0F12), precise brand blue (#2196F3), dark blue (#1565C0), warm amber sunlight, selective mint accents (#1AD191), and rare brand yellow (#FFC107) only where a real call-to-action or high-value highlight would naturally appear.
- Environment rule: if a person is using a laptop, reviewing analytics, designing, or working on a campaign, place them in a professional MediaBubble-style office or studio, never a casual cafe. Prefer clean white walls, deep brand-blue feature walls with tasteful abstract typography or letterform texture, deep-charcoal desks, glass meeting rooms, and occasional yellow accent walls used deliberately.
- Lighting: cinematic but believable; warm Egyptian sun, clean professional interiors, crisp contrast, no glossy stock-photo overproduction.
- Geography: must feel specifically like Hurghada / Red Sea / Egypt, never Dubai, the Gulf, Maldives, generic Mediterranean, or anonymous stock photography.
- Architecture: Egyptian coastal vernacular where relevant: flat roofs, white or sand-coloured plaster, mashrabiya details, terracotta accents, palms, bougainvillea, modest resort scale, human-scale marina buildings. Avoid glass towers, Gulf skylines, over-luxury mega-resorts, or water villas.
- People: every visible human must look between 25 and 35 years old unless the prompt explicitly says there are no people. Egyptian people should feel real and professional, not model-like or over-posed. Clothing should be casual-professional and practical for coastal Egypt.
- Image quality: authentic photorealistic photography, natural skin, believable hands, realistic devices, realistic reflections, no AI artifacts.
- Text rule: no readable text, labels, watermarks, subtitles, fake logos, or UI overlays unless a prompt explicitly asks for a screen. If screens, signage, brochures, or dashboards appear, they must contain abstract shapes, unreadable microtext, or blurred/non-legible UI only.
```

Use this negative instruction at the end of every prompt when the generator allows it:

```text
Avoid: AI artifacts, warped hands, over-smoothed skin, plastic faces, readable text, fake logos, watermarks, stock-photo poses, Dubai towers, Gulf skyline, Maldives water villas, generic beach-resort cliches, heavy filters, neon colors, one-note beige palette.
```

## Quick API Snippet

```javascript
import OpenAI from 'openai';

const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

async function generateImage(prompt, size = '1792x1024') {
  const response = await openai.images.generate({
    model: 'dall-e-3',
    prompt,
    n: 1,
    size,
    quality: 'hd',
    style: 'natural',
  });

  return response.data[0].url;
}

const url = await generateImage(`
  Photorealistic aerial drone photograph taken at 80 meters over Hurghada marina
  and the Red Sea coastline, Egypt, at golden hour...
`);
```

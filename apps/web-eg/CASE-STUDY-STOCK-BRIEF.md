# Case Study Stock Brief

This stock set is for MediaBubble's case-study and showcase surfaces. The goal is not generic "business people" photography. Each image should feel like MediaBubble produced the work, documented the process, and captured the business impact in a premium Hurghada context.

## Visual Rules

- Mix people-led and no-people scenes.
- Keep scenes grounded in Hurghada, the Red Sea, or MediaBubble's indoor-outdoor studio language.
- Use MediaBubble's visual temperature:
  - deep navy and brand-blue accents
  - warm wood and stone
  - clean whites
  - restrained brand-yellow accents
- No text overlays inside images.
- Avoid readable report copy, brochure headlines, software UI labels, or visible client logos.
- Expressions should feel real and confident, not exaggerated stock-photo smiles.
- Use editorial realism over corporate staging.

## Coverage Model

For each case-study family, aim to keep this balance:

1. One people-led "results" image
2. One people-led "process" image
3. One production or fieldwork image
4. One no-people tabletop/document image
5. One no-people environment image

This creates a reusable library that can cover:

- homepage showcase cards
- case-study hero replacements
- gallery images
- blog and insight covers
- service and process sections

## Best Usage

- Use people-led shots when the story is trust, collaboration, growth, or visible business impact.
- Use no-people shots when the layout needs a calmer image, when text overlay is heavier, or when the story is materials, systems, or environment.
- Avoid using the same stock image across adjacent cards or sections.
